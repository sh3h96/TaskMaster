# Task Master 📝

Task Master is a professional, cross-platform Flutter application designed to help users efficiently manage their daily tasks and boost productivity. 

## ✨ Features
- **Task Management**: Seamlessly add, edit, and delete tasks.
- **State Management**: Built using `Provider` for highly responsive and optimized UI updates.
- **Local Storage**: Utilizes `shared_preferences` to persist data locally, ensuring your tasks are saved even when the app is closed.
- **Cross-Platform**: Compiles natively to Android, iOS, Web, and Desktop.

## 🛠️ Built With / Packages
This project leverages modern Flutter development practices and relies on the following key packages:
- **[Flutter](https://flutter.dev/)**: The core UI toolkit for building natively compiled applications.
- **[Provider (^6.1.2)](https://pub.dev/packages/provider)**: For clean, scalable, and efficient state management.
- **[Shared Preferences (^2.3.2)](https://pub.dev/packages/shared_preferences)**: For robust local data persistence.
- **[Flutter Launcher Icons (^0.13.1)](https://pub.dev/packages/flutter_launcher_icons)**: To generate and manage custom app icons automatically.

## 📁 Project Structure
The app follows a clean architecture pattern to separate logic from the UI, ensuring the code remains maintainable and scalable.
